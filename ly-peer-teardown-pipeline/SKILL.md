# LY同行拆解流水线：同行账号 → 研究报告 → 五区素材库

一条流水线把任意短视频同行账号扒透，产出三件套：

1. **完整同行研究报告**（七段：基本信息/定位/核心方法论/爆款规律/评论区信号/作品全列表/跨平台与价值判断）
2. **蒸馏卡**（五段速查：核心公式/爆款规律/标题公式/价值/已处理作品）
3. **五区素材库**（A标题 / B开场钩子 / C观点金句 / D案例 / E结构模板）+ 多账号总索引

## 输出路径约定（重要）

所有输出统一存到**当前工作目录下的 `同行素材库/{账号名}/`**，目录不存在就自动创建。不写死任何绝对路径（每台机器的目录都不一样）：

```
同行素材库/
├── 00-总索引.md                        （多账号时维护）
└── {账号名}/
    ├── {账号名}-完整同行研究报告.md
    ├── {账号名}-蒸馏卡.md
    ├── 素材库-{账号名}.md
    └── 原始资料/                       （中间产物，不入交付）
        ├── manifest.json               （作品清单，可选）
        └── 重点视频原始页面文本/*.txt   （每条视频一个页面文本）
```

## 输入说明

- **原始页面文本（核心输入）**：每条视频一个完整页面文本（含标题/章节要点/互动数字/评论区）。来源：
  - 有浏览器控制能力的 agent：见「阶段一」自动抓取
  - 没有的：手动打开抖音视频页，全选复制正文存成 txt（文件名 `{视频ID}-{标题}.txt`），或直接贴页面内容让 agent 分析
- **作品清单（可选）**：manifest.json 或任何含 作品ID/赞数/标题 的列表，用于作品全表和数量核对；没有就用页面文本清单
- **最少可用**：哪怕只有几条视频的页面文本或评论区，也能开工；缺数据的项如实标注「仅有清单数据/未获取」，不编造

## 阶段一：抓取详情页（可选）

- 有 CDP/浏览器自动化能力（如 Hermes 的 browser_navigate + browser_cdp，本机 Chrome 开 localhost:9222）：直访 `https://www.douyin.com/video/{id}`
  - 导航后显示「视频数据加载中」是常态：先暂停+静音所有 video（防连播跳走），再等 8-12 秒重试；仍失败标「页面未获取」
  - Runtime.evaluate 必须带 target_id（先 Target.getTargets 找 type=page 的 douyin target），否则报 -32601
  - 正文区在「章节要点」之后、「推荐视频」之前：标题（常带「第N集|」前缀）、发布时间、互动数据（点赞X|评论X|收藏X|分享X）、章节要点全文、可见评论含作者回复
  - 落盘：`同行素材库/{账号名}/原始资料/重点视频原始页面文本/{video_id}-{标题前10字}.txt`，UTF-8，文件名去掉「第N集|」前缀和#标签
- 没有浏览器自动化：手动保存页面文本，效果等价

## 阶段二：完整研究报告 + 蒸馏卡

模板结构见 `references/report-and-distillation-card-template.md`（已内嵌，无需外部标杆文件）。

工作流：
1. **读模板**，固定结构照抄：报告七段 + 蒸馏卡五段
2. **读页面文本**：一律用 Python 自动检测编码批量读（utf-8-sig → utf-8 → gbk → utf-16 依次尝试），不要用 read_file 逐个读（中文 UTF-8 常被误判 binary）
3. **结构化提取**：优先跑 `scripts/extract_douyin_pages.py <目录> <输出.json>`，解析锚点见 `references/douyin-page-text-parsing.md`；无 Python 环境就让 agent 按锚点手动提取
4. **分批读压缩结果**：按 10 条一批打印（要点+数据+评论），边读边记笔记，别把全文倒进上下文
5. **写两件套**：UTF-8 写入 `同行素材库/{账号名}/`；互动数据从页面文本读取，**不得编造**
6. **验证**：Python 检查两文件存在且 UTF-8 可解码

报告写作纪律：
- 证据边界：实锤标 ✅、推断标 ⚠️（页面文本里没有的证据不要写成实锤）
- 「对用户的价值判断」拆「能抄的 / 别学的」，每条给可操作的具体做法
- 评论区信号是重要章节：作者回复、带赞数热评、质疑评论、水军/养号信号（固定账号每条必评 = 疑似互评养号；同质好评刷屏 = 软广实锤）
- 爆款规律分层给数据（大爆款/中爆款/常规/低流量 + 代表），提炼可复用的标题公式
- 蒸馏卡头部写「一句话定位」，末尾「已处理作品（N条，日期基线）」按主题分组

## 阶段三：素材库五区 + 总索引

1. **读研究报告**：分段全读，提炼身份定位/核心方法论/爆款规律/变现路径/重点视频详情表
2. **挑重点作品**：优先读统计文件或按赞数取前 20%（作品量大不用全读页面）；报告已全时也要精读 2-4 份最高价值原文——爆款提示词视频（评论区热评常贴提示词全文 = C区金句现成素材）、与用户同赛道或同主课的视频（章节要点 = E区结构模板）
3. **拆素材点**：五区 A标题(≈7) / B开场钩子(≈4) / C观点金句(≈10) / D案例(≈6) / E结构模板(≈8)，每点固定格式：
   ```
   ### X-001 名称 已用[ ]
   - **内容/金句/原例**：...
   - **来源**：视频名（赞·收藏）
   - **怎么套**：面向用户（短视频/知识付费内容创作者）的具体场景，给可直接改的句式
   - **数据说明**：收藏率（收藏÷赞，教程型 60%+ 是强信号）、数据强弱、同主题其他条
   ```
4. **去重**：同主题只留数据最强一条（按赞数），弱条并入强条「怎么套」；句式独特但数据弱的可保留并注明「数据弱仅作结构参考」
5. **写红线区**（必含）：①引用标来源；②金句借鉴不搬原画面（版权）；③该博主实际踩过的坑（别踩）；④竞品预警（业务撞车时单列「别照抄他的定位」+ 差异化方向）；⑤话术路线冲突（如他喊「搞米」、你走软词路线）别学；⑥不可规模化的变现模式别学；⑦数据时效（采集快照，引用大数字先核对）
6. **登记总索引（多账号时必做）**：`同行素材库/00-总索引.md` —— 总表新增行（想做什么内容 | 首选博主 | 素材点 | 备选博主）+ 各库速查表 + 重算合计。**此文件可能被并行编辑**：patch 前先读当前内容、锚点取唯一上下文，改完复核「合计 == 数字行之和」
7. **收尾**：统计素材点数 `re.findall(r'^### ([A-E]-\d+)', text, re.M)`（「已用[ ]」计数会比素材点多 1，属正常）；中文汇报「拆了X个素材点 + 文件路径」

## 通用陷阱

- **编码**：read_file 对中文 UTF-8（尤其带 BOM 的 UTF-8-SIG）误判 binary；统一用 Python smart_read（utf-8-sig → utf-16 → gb18030 → utf-8）
- **互动数据顺序**：标题行后紧跟 4 个数字 = 赞/评论/收藏/分享（不是赞/收藏/评论）；可靠锚点用「发布时间：」往前 ~160 字符，**不要用「举报」**（页脚 ICP 备案区也有「举报」会截到噪音）
- **页面噪音**：导航栏/推荐视频/「大家都在搜」/ICP备案，提取时丢弃；评论区截止于「暂时没有更多评论」或「推荐视频」
- **详情页数字会浮动**：详情页点赞可能与清单不一致，以详情页抓取为准
- **无口播正文的视频**（录屏大字流）：方法论只能从标题系列结构+评论区行为归纳，⚠️标注，禁止编造
- **评论区金句价值可能超过正片**（「作者赞过」的热评），可单列素材点
- **文件名编号 ≠ 报告表格序号**：NN_ 前缀按视频ID排序，与报告「重点视频详情表」# 序号不对应，按 TITLE 行内容映射
- **账号主页数据**（粉丝/获赞/IP）藏在视频页内嵌文本里（如「粉丝400.4万获赞1542.5万」），IP 看评论区作者属地

## 支持文件

- `references/report-and-distillation-card-template.md` — 报告+蒸馏卡模板结构（七段/五段）
- `references/douyin-page-text-parsing.md` — 页面文本解析锚点 + 素材库格式结构 + 实测案例
- `scripts/extract_douyin_pages.py` — 批量提取页面文本结构化字段（可选加速，需 Python）
- `scripts/parse_douyin_page_text.py` — 逐文件解析（可选加速，需 Python）

## 使用说明

- 依赖：能读写文件的 agent（Hermes / WorkBuddy / Codex 均可）；Python 仅脚本加速用，没有也能干
- 安装：把本文件夹放进所用 agent 的 skills 目录（Hermes: skills/、Codex: .agents/skills/、WorkBuddy: skills/），agent 自动识别
- 所有输出在 agent 的当前工作目录下的 `同行素材库/` 中，随用随建，无固定路径要求
