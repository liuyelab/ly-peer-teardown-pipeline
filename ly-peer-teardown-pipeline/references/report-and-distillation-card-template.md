# 报告 + 蒸馏卡模板结构

本文件即模板结构，直接照此执行，无需外部标杆文件。

## 完整同行研究报告（七段）

1. **基本信息表**：昵称（含话题标签）/ 本人 / 抖音号或ID段 / 粉丝 / 获赞 / 作品数（注明几条全读）/ IP属地 / 变现方式 / 内容方向 / 更新频率。粉丝获赞从页面文本尾部 `粉丝X万获赞Y万` 读，注明采集时间。
2. **一、他的定位**：2-4 段——他是谁、卖什么、数据/身份背书、对使用者（你自己的账号/业务）的意义（一句话点破"能对标什么"）。
3. **二、核心方法论体系**：按主题归并为 4-7 个方法块，每块标题后标 ✅实锤（标题/评论区可证）或 ⚠️推断。页面文本无口播正文时，方法论只能从**标题系列结构 + 评论区行为证据**归纳，并在开头声明证据边界。给可直接抄的话术原文（如"请填写卡片哦""XX都整理好了"）。
4. **三、爆款内容规律**：数据分布（断层/区间）、什么内容相对好（按赞数排名+原因）、标题公式（每条给句式 + 实例）。
5. **四、评论区信号**：按 转化信号 / 口碑背书 / 质疑负面 / 作者行为 分列，每条带赞数；这是卖课同行最有价值的章节。
6. **五、作品全列表**：按赞数倒序，| # | 标题 | 点赞 | 发布时间 |；赞数与 manifest like + 文件名前缀双核对。
7. **六、跨平台** + **七、对用户的价值判断**：能抄的（具体到可移植话术/结构，6 条左右）+ 别学的（含风险理由，4-5 条）。文末注：报告生成时间 + 数据来源声明。

## 蒸馏卡（五段速查版）

- 标题 `# {账号名}（{昵称}）蒸馏卡`；开头引用块：来源（N条全读+日期）、定位一句话、证据边界 `✅实锤 ⚠️推断`
- **核心公式**：一句话公式 + 分步展开（卖课号给转化链路；教程号给流量引擎；观点号给内容支柱）
- **爆款规律**：按赞数排的数据事实 + 归因（刚需/新功能流量/收藏驱动等）
- **标题公式**：每条句式 + 实例
- **对用户的价值**：能抄（对齐使用者自己业务的落点）/ 别学（风险）
- **已处理作品**：全部作品名+赞数，标注基线日期（`20条，2026-08-12 基线`）

## 写作纪律
- 互动数据一律从页面文本/采集清单读，不编造；方法论推断项必须标注 ⚠️
- 评论区金句和作者话术是核心弹药，原样引用并带赞数
- 输出 UTF-8，路径用 Windows 反斜杠全路径
- 完成后中文汇报：每账号 读了几条 + 两文件路径 + 核心方法论一句话
